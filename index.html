How To Personalize This Website

Everything on this site is fully customizable! At the top of the <script> tag in this HTML file, you will find the master object named CONFIG.

✏️ partnerName: Change her name or nicknames.

✏️ relationshipStartDate: Set your exact date string for the counter.

✏️ photoList: Add your real photo paths or image URLs!

✏️ musicPath: Link your favorite MP3 file (e.g. audio/our-song.mp3).

✏️ timelineEvents & loveLetter: Edit any memories or letter text.
